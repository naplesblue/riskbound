# 方法：怎样诚实地检验一条技术规则

本项目的结论与负面结果都来自同一套纪律。`riskbound.harness` 把其中可复用的部分（记账、对照、统计、定级）原样移植出来，你可以拿它检验自己的规则。

[English](methodology.en.md)

## 1. 预登记

- 规格（指标、参数、对照、最小效应、格子与检验家族）先写成文件并冻结，记录其 sha256。
- 看到结果之后不改参数、不换对照、不调最小效应、不增删格子。
- 想换口径就另起一批检验，并把旧结果保留。

## 2. 两期独立、同向才算

- 两个时期各自独立运行（本项目：early 2016-09-20 ~ 2021-09-17，late 2021-09-20 ~ 2025-12-31），指标各自从缓存起点预热。
- 只有两期**同号**、且各自达到最小效应，才可能定为「方向一致」。

## 3. 对照：比较的对象决定结论

| 对照 | 用于 | 构造 |
|---|---|---|
| 等暴露买入持有 C† | 连续仓位规则（如波动率目标） | 静态买入持有账户：d₀ 满仓，d₁ 开盘一次调到初始权重 c，此后不再交易。二分求 c，使对照的**实际平均仓位**等于策略的实际平均仓位：残差 ≤ 1e-9 停止，≤ 1e-6 才有定级资格；未匹配的股票-期不进入该格。 |
| 随机时点洗牌 P(F) | 两档段式规则（如 200 日线半仓） | 保持段数与段长多重集合不变、末尾未恢复段固定，只随机重排时点；200 次。 |

为什么不用「初始权重 = 平均仓位」：仓位会随价格漂移，那样的对照实际暴露更高，能凭空制造出回撤优势。C† 匹配的是实际平均暴露，但不匹配暴露的时间分布——它回答「同样的平均仓位放在一次性的静态配置里会怎样」。

## 4. 统计

- 每格每期：每只股票一个统计量 g（如回撤差），无信息的股票 h = 0 不计入；期内统计量为股票等权平均；T = 两期平均。
- **按股票分块的 shift-bootstrap**：2000 次重抽股票，两期共用同一组重数；p = (1 + #{|T* − T| ≥ |T|}) / (B′ + 1)。
- **不可检验规则优先**：任一命中即 p = 1、定级「无法估计」，先于任何方向判断。
  - 规则 1：任一期有信息的股票 < 10；
  - 规则 3：无定义的重抽 > 5%；
  - 规则 4：任一期有信息分块 < 10；
  - 规则 5：T* 分布退化（max − min = 0）。
  （编号沿用原检验规格；规则 2 只适用于二元结局，这里不用。）
- **Holm 家族校正**：家族内所有格（含不可检验格，p = 1）一起校正。
- **三级标签与 Holm 分列**：方向一致（两期同号、各自达到最小效应、参照子集同号）/ 不一致（两期反号且都达标）/ 无法估计（其余）。三级标签不以 Holm 显著为门槛，两者并列报告，不合并成一句话。
- **最小效应**：回撤 1.0pp，Sharpe / Calmar 0.05。

## 5. 为什么不能只报胜率

胜率的基线随市场环境与个股大幅变化（见 [负面结果 §6](negative-results.md)）。不带同期基线的胜率，无法区分「规则有用」与「那段行情本来就涨」。本项目的每一个比较都相对同期、同宇宙的对照。

## 6. 用 harness 检验你自己的规则

```python
from riskbound import rules
from riskbound.harness import evaluate_overlay, evaluate_segments, CellSpec

# bars: {symbol: DataFrame(O, H, L, C, V)}，每只股票一段完整历史（含第一期之前的预热）
periods = [("2016-09-20", "2021-09-17"), ("2021-09-20", "2025-12-31")]

def target_fn(C):          # 收到截至「上一个收盘」的收盘序列，返回逐收盘的目标仓位
    return rules.weights(C, vol=True, vol_floor=None, below_sma=1.0)["w"]

res = evaluate_overlay(bars, target_fn, periods)          # 连续仓位 → 等暴露对照 C†
print(res.to_markdown())
```

- `evaluate_overlay`：默认格为回撤（1.0pp）与 Sharpe（0.05），对照 C†；`rebalance="threshold"`（0.10 门槛）或 `"change"`。
- `evaluate_segments`：目标只取 {1, low} 两档的段式规则，默认格为回撤与 Calmar，对照为随机时点洗牌（`n_shuffle=200`）。
- `CellSpec(name, metric, control, min_effect, predicted_sign)`：自定义格；Holm 家族就是你传入的格的顺序。
- `subset`：可选的参照子集。给定时要求子集两期与总体同号；子集在某期没有有效成员时该格「无法估计」（`subset_check: no informative members`）；不给时 `subset_check: skipped`。
- 默认 `seed=20261005`、`n_boot=2000`、成本 10 bps。示例见 `examples/evaluate_my_rule.py`（合成数据，结果不构成任何证据）。

注意：

1. **`periods` 应恰好给两期。** 多于两期时，T 取全部期的平均、达标判定覆盖全部期，但同号判定只比较前两期。
2. **单期**只返回描述统计，verdict 为 `not_applicable (single period)`，不做 bootstrap 与定级。
3. **各期独立锚点**：harness 的契约是「每只股票一段完整历史、指标在整段上算」。若要像本项目回测那样让每一期的扩张中位数从该期自己的起点算，需要在 `target_fn` 内按 `len(C)` 判断所在期并从对应起点计算——harness 只把截至该期最后一个目标所用收盘的数据交给 `target_fn`，所以长度能唯一确定期别。
4. `target_fn` 拿不到期末之后的数据；这是结构性的「无未来信息」保证，但你的函数本身仍须只用 ≤ t 的数据。
