# 负面结果：没有通过检验的规则

研究起点是一组常见的 K 线形态与买点规则。它们在同样的纪律下（预登记、同期基线 / 同环境对照、两期同向、多重比较校正）都**没有表现出稳定的增量**。本文只写结论、对照方式与规模，不复述规则来源的原始描述。

这些结果也是 riskbound 不带「止跌 / 滞涨」类纪律标签的原因：它们在检验中没有预测力。

[English](negative-results.en.md)

## 1. 见顶 K 线形态

- **范围**：上吊线、流星、黄昏之星、看跌抱线、阳孕阴、缩量上涨、乖离、KDJ 超买、61.8% 回撤位失守等 12 个检测器；两期 × 两个宇宙（后者是前者的子集，并不独立）。
- **对照**：同宇宙、同期、同环境的全部交易日。
- **结果**：主指标「h 日内收盘未突破形态高点」上有看似方向一致的格，但事后诊断发现它被**屏障距离**主导：形态高点离收盘越远，越不容易在 20 日内被收复，这与「形态预示下跌」无关。不设屏障的三个次指标（h 日收益 < 0 的比例、收益均值差、20 日内先触 −1×ATR）没有跨组合一致的优势。
- **结论**：对「形态预示下跌」没有证据；对「失效位放在哪里」有参考价值。

## 2. 位置 × 形态

- **范围**：五类见顶形态 × 多种关键位置定义，共 50 个定级格。
- **对照**：(b) 同位置但无形态的交易日，检验「形态在位置上的增量」；(c) 有形态但不在位置上的交易日，检验「位置的增量」。
- **结果**：方向一致 0 格、不一致 4 格、无法估计 46 格；Holm 校正后拒绝 0 格。61.8% 失守在非科技股宇宙上也只有 T = +2.1pp、p = 0.27。
- **结论**：「形态在关键位置上有增量」与「位置本身有增量」都没有得到支持。

## 3. 实战式止跌 / 滞涨定义

- **范围**：按实战描述写成可计算定义的止跌、滞涨及其位置变体，5 个定级格。
- **对照**：同宇宙同期的全部交易日（主指标：20 日内先触下界的概率）。
- **结果**：方向一致 0 格。止跌之后并没有更少先触下界（两期 +1.7 / +2.6pp，与预测相反但未达 3pp）；滞涨之后也没有稳定地更多先触下界（-0.6 / +3.1pp）。
- **短窗口（1–20 日）描述性检查**：方向命中率与全体交易日没有稳定差异；失效率低于全体交易日，但这是因为失效位由触发日 K 线本身定义，不构成预测力。

## 4. 滞涨减半仓

- **范围**：滞涨出现时减到半仓、按规则接回的仓位管理，25 只两期。
- **对照**：同样段数、同样段长、只换时点的随机半仓（200 次洗牌）。
- **结果**：回撤没有更小（两期都略差，未达 1pp）；Calmar 两期都更差约 0.08（方向一致、**与预测相反**，Holm p = 0.002）。差在收益：按规则选出的半仓时点，收益只在 31% / 29% 的随机洗牌中更高。
- **结论**：这套规则选出的减仓时点，不如同长度的随机时点。

## 5. 买点规则

一组九类买点规则：样本越大，相对随机交易日的增量越接近 0；多数规则的可执行定义依赖未公开的资料，无法形成唯一判定。本项目不展开这些规则的内容。

## 6. 贯穿规律：胜率必须带同期基线

把市场按无未来信息的环境标签分桶后，20 日持有的「胜率」基线本身就随环境大幅变化：recent 期各桶约 53%–80%，early 期约 62%–71%；而且同一类环境在两期的高低方向相反（2020 年 3 月急跌后的 V 形反弹落在「下跌高波动」桶里，使它成为 early 期最高的一桶）。来源：私有研究档案中的市场环境分析（2026-09-22）。

所以，**任何不带同期基线的胜率数字都没有意义**：一条规则看起来不错的胜率，可能只是它所在环境的基线本来就这么高。
